## 2. 本地数据提交策略

| 路径 | 策略 | 原因 |
| --- | --- | --- |
| `data/creative-knowledge/` | 忽略 | 本地知识库运行数据，包含资产、反馈、run、调度状态等，属于机器运行产物。 |
| `data/material-analysis/` | 忽略 | 素材分析导入、视觉缓存、报告、提示词池属于本地运行产物，可能体积大且随真实数据变化。 |
| `data/acceptance-*.png` | 忽略 | 页面验收截图可本地留存，不作为默认代码提交内容。 |
| `data/tmp-*.xlsx` | 忽略 | 临时工作簿和中间复制文件不进入版本库。 |
| `public/generated/` | 忽略 | 提示词池 JS 快照由素材分析导出生成，不作为源代码维护。 |
| `sucai/~$*.xlsx` | 忽略 | Excel 临时锁文件。 |
| `sucai/` | 暂不全局忽略 | 当前项目仍把 `sucai` 当成本地种子方向和素材数据来源；是否提交脱敏样例，后续单独决定。 |

已落实到 `.gitignore`。
