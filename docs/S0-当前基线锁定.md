# S0：当前基线锁定

> 更新日期：2026-05-27  
> 目标：把当前已经跑通的 `自动选题 -> Agent 生成 prompt -> Prompt Gate -> Legil 生图 -> assets.json 入库` 锁成后续开发的回归基线。

## 1. 当前能力清单

### 页面入口

| 页面 | DOM 入口 | 当前用途 | S0 要求 |
| --- | --- | --- | --- |
| 量产 | `massPageTab` / `massPage` | 批量提示词、Legil 生图、完整旧工作流 | 保留入口和旧功能 |
| 改尺寸 | `resizePageTab` / `resizePage` | 即梦 AI / Legil 批量改尺寸 | 保留入口和旧功能 |
| 创意拓展 | `creativePageTab` / `creativePage` | Agent 表格拓展、创意批量生图、运行一次自动创意 | 保留入口，并显示自动创意状态 |
| 重命名 | `renamePageTab` / `renamePage` | 重命名、改尺寸、加 LOGO、一键打包 | 保留入口和旧功能 |

### 已锁定接口

| 接口 | 用途 | S0 验收点 |
| --- | --- | --- |
| `GET /api/creative-auto/status` | 返回自动创意状态、额度、preflight、下一方向 | 能看到 `status`、`quota`、`suggestion.next` |
| `GET /api/creative-auto/suggestion` | 单独返回下一方向建议 | 能看到下一方向候选和原因 |
| `POST /api/creative-auto/run-once` | 启动一次自动创意 | `agentOnly: true` 只生成 prompt；默认会进入 Legil |
| `GET /api/creative-auto/runs/:runId` | 查询单次 run 明细 | 能追溯 prompt、Prompt Gate、Legil、assets |
| `POST /api/legil/creative-batch` | 创意拓展小批量生图执行入口 | 至少 1 条 prompt 能生成 4 张图 |
| `GET /api/legil/creative-progress` | 查询 Legil 创意批量进度 | run-once 能轮询并写回进度 |
| `POST /api/legil/stop` | 停止当前 Legil 任务 | 自动创意暂停/停止可复用 |

### 已锁定文件与数据

| 文件 / 目录 | 用途 | S0 验收点 |
| --- | --- | --- |
| `src/routes/creative-auto.routes.js` | 自动创意 HTTP 路由 | status、run-once、run detail 路由存在 |
| `src/services/creative-auto/index.js` | 自动选题、Agent、Prompt Gate、Legil 编排 | agentOnly 和 Legil run-once 均可执行 |
| `src/services/creative-auto/prompt-gate.js` | prompt 质检、去重、禁用词、额度截断 | rejected/accepted 报告可复测 |
| `src/services/creative-auto/assets.js` | 生成图资产入库 | `assets.json` 记录 `runId`、prompt、参数、文件路径 |
| `data/creative-knowledge/runs/*.json` | 单次 run 全过程记录 | 能按 `runId` 找回一次运行 |
| `data/creative-knowledge/assets.json` | 图片资产索引 | 图片不是孤立文件 |
| `public/index.html` | 页面入口和自动创意面板 | 四个页面入口仍在，自动创意按钮仍在 |
| `public/js/creative-auto.js` | 自动创意前端状态与启动逻辑 | 页面能刷新状态、启动、轮询 run |

## 2. 基线 run 样例

当前保留的真实成功样例：

```text
Run ID: creative_run_20260526_200045_53b7a7
Prompt count: 1
Images saved: 4
Output folder: D:\工作\自动化工作流1\创意拓展\输出
Assets written: data/creative-knowledge/assets.json
```

这个 run 是后续判断“真实链路曾经跑通”的基线样例。后续如果接口、页面或数据结构调整导致同类 run 不能完成，应先修复 run-once，再进入 S1 或 24 小时循环。

## 3. 自动基线脚本

运行：

```bash
npm run test:s0-baseline
```

脚本覆盖：

| 检查 | 覆盖内容 |
| --- | --- |
| 静态入口检查 | 四个页面 tab、四个页面 section、自动创意按钮、前端调用路径 |
| route/asset 检查 | creative-auto 路由、assets 写入器、run-once 资产来源字段 |
| status 服务检查 | 状态、额度、preflight、下一方向 |
| agentOnly 检查 | `runOnce({ agentOnly: true })` 完成 Agent + Prompt Gate，不启动 Legil |
| Prompt Gate 回归 | 本轮重复、历史重复、禁用词、额度截断 |
| 小批量 Legil stub | 2 条 prompt x 4 张图，写入 8 条 assets，并保留 runId |

现有细分脚本仍可单独运行：

```bash
npm run test:creative-auto
node scripts/test-creative-auto-prompt-gate.js
node scripts/test-creative-auto-run-once-legil.js
```

## 4. 手动真实验收步骤

自动脚本使用 stub，不消耗 Legil 额度；真实验收仍按下面步骤做。

1. 启动服务：

```bash
npm start
```

2. 打开：

```text
http://localhost:3066
```

3. 页面入口验收：

| 页面 | 你看什么 |
| --- | --- |
| 量产 | tab 还在，原来的目录、模型、启动、日志能力还能打开 |
| 改尺寸 | tab 还在，输入输出目录、尺寸选项、启动按钮还能打开 |
| 创意拓展 | tab 还在，能看到“运行一次自动创意”面板 |
| 重命名 | tab 还在，重命名、改尺寸、加 LOGO、打包区块还能打开 |

4. 状态接口验收：

```bash
curl http://localhost:3066/api/creative-auto/status
```

需要看到：

```text
success: true
quota.remainingImagesToday
suggestion.next
preflight.checks
```

5. Agent-only 验收：

```bash
curl -X POST http://localhost:3066/api/creative-auto/run-once ^
  -H "Content-Type: application/json" ^
  -d "{\"agentOnly\":true,\"maxPrompts\":1}"
```

需要看到：

```text
success: true
run.agentOnly: true
run.runId: creative_run_...
```

之后用 `GET /api/creative-auto/runs/:runId` 确认：

```text
phase: agent_completed
promptQualityReport.acceptedPromptCount >= 1
legilPayload: null
```

6. 小批量真实 Legil 验收：

在创意拓展页使用默认小批量或传 `maxPrompts: 1` 运行一次非 agentOnly：

```bash
curl -X POST http://localhost:3066/api/creative-auto/run-once ^
  -H "Content-Type: application/json" ^
  -d "{\"maxPrompts\":1}"
```

需要看到：

```text
至少 1 条 prompt 进入 Legil
至少保存 4 张图
run.phase 最终为 legil_completed
run.legilResult.savedCount >= 4
run.assets.newAssetCount >= 4
```

7. 输出目录验收：

```text
D:\工作\自动化工作流1\创意拓展\输出
```

需要看到本轮新生成图片。

8. 资产记录验收：

打开：

```text
data/creative-knowledge/assets.json
```

任取本轮图片，需要能看到：

```text
runId
source: creative-auto-run-once
directionId / directionPath
promptHash / prompt
filePath
generationSettings
```

## 5. S0 通过标准

```text
你确认当前 run-once 是可用的；
后续开发可以在这个基础上继续扩展；
如果后续改坏这个能力，必须优先修复。
```

## 6. S0 不通过处理

```text
先修复 run-once；
不继续做知识库页和 24 小时循环；
优先恢复 status、agentOnly、Legil 小批量、assets.json 写入、四个页面入口。
```
