# 接口清单

这份文档按功能列出后台接口，方便你知道页面按钮大概会调用哪里。

## 浏览器和文件夹

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| `GET` | `/` | 打开主页面 |
| `POST` | `/api/count-images` | 统计文件夹里的图片数量 |
| `POST` | `/api/select-folder` | 打开本机文件夹选择窗口 |
| `POST` | `/api/open-website` | 打开单个网站 |
| `POST` | `/api/open-both-websites` | 打开自动化需要的网站 |
| `POST` | `/api/close-browser` | 关闭浏览器 |
| `GET` | `/api/browser-status` | 获取浏览器状态 |

## 创意知识库

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| `GET` | `/api/creative-knowledge/status` | 查看知识库导入状态、数据文件和统计 |
| `POST` | `/api/creative-knowledge/import` | 从本地 `sucai` 重新导入方向、TOP 素材和参考图索引 |
| `POST` | `/api/creative-knowledge/import-directions` | 只重新导入方向表 |
| `GET` | `/api/creative-knowledge/overview` | 查询知识库只读总览，聚合方向、TOP 素材、参考图、资产、反馈和 run 数量 |
| `GET` | `/api/creative-knowledge/directions` | 查询方向列表，支持搜索、分页和自动运行筛选，并返回只读 `knowledgeStats`、参考图和方向资产统计 |
| `GET` | `/api/creative-knowledge/assets` | 查询生成图片资产，支持搜索、分页、按 runId / directionId / 文件存在状态筛选 |
| `GET` | `/api/creative-knowledge/assets/:assetId/file` | 读取资产对应的本地图片文件，用于知识库页缩略图和打开图片 |
| `GET` | `/api/creative-knowledge/references/:referenceId/file` | 读取方向参考图文件，用于方向库缩略图和打开大图 |
| `GET` | `/api/creative-knowledge/runs` | 查询最近自动创意运行记录，支持搜索、分页和状态筛选 |
| `GET` | `/api/creative-knowledge/top-material-insights` | 查询 TOP 素材洞察，供自动选题和 Agent 上下文使用 |

## 运行一次自动创意

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| `GET` | `/api/creative-auto/status` | 查看当前状态、preflight、今日额度和下一方向 |
| `GET` | `/api/creative-auto/suggestion` | 查看自动选题建议、候选方向和额度 |
| `POST` | `/api/creative-auto/run-once` | 启动一次自动创意；`agentOnly: true` 时只生成 prompt，不调用 Legil |
| `POST` | `/api/creative-auto/runs/:runId/start-legil` | 从某次 run 的 Prompt Gate 结果继续启动 Legil，支持只发送被选中的 prompt |
| `GET` | `/api/creative-auto/runs/:runId` | 查看指定 run 的 Agent、Prompt Gate、Legil 和资产入库详情 |

## 素材分析

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| `POST` | `/api/material-analysis/import` | 导入 CSV/XLSX 素材表，生成标准化数据、Top100 和导入摘要 |
| `GET` | `/api/material-analysis/imports` | 查看历史素材分析导入记录 |
| `GET` | `/api/material-analysis/imports/:runId` | 查看某次素材分析导入详情 |
| `GET` | `/api/material-analysis/imports/:runId/top100` | 查看某次导入的 Top100 素材 |
| `GET` | `/api/material-analysis/imports/:runId/overview` | 查看项目指标、健康度和 Top100 总览 |
| `GET` | `/api/material-analysis/imports/:runId/directions` | 查看方向级表现聚合 |
| `POST` | `/api/material-analysis/imports/:runId/vision/start` | 启动 Top100 或指定素材的 AI 视觉识别 |
| `GET` | `/api/material-analysis/imports/:runId/vision/status` | 查看视觉识别任务进度、成功数、失败数和缓存命中 |
| `GET` | `/api/material-analysis/imports/:runId/vision/results` | 查看视觉识别结果 |
| `POST` | `/api/material-analysis/imports/:runId/reports/generate` | 生成素材分析周报和经验文档 |
| `GET` | `/api/material-analysis/imports/:runId/reports` | 查看周报和经验文档路径及摘要 |
| `POST` | `/api/material-analysis/imports/:runId/reports/open` | 打开周报或经验文档所在位置 |
| `POST` | `/api/material-analysis/materials/:materialId/creative-brief` | 基于单个素材生成创意拓展 brief |
| `POST` | `/api/material-analysis/directions/:directionKey/creative-brief` | 基于方向聚合生成创意拓展 brief |
| `POST` | `/api/material-analysis/imports/:runId/creative-plan` | 生成下周创意拓展计划或 Agent 任务包 |
| `GET` | `/api/material-analysis/imports/:runId/creative-targets` | 按一级/二级/三级/具体创意点聚合可拓展目标 |
| `GET` | `/api/material-analysis/creative-expansions` | 查看本地创意提示词池列表 |
| `POST` | `/api/material-analysis/imports/:runId/creative-expansion` | 基于勾选的 TOP100 视觉方向生成拓展提示词池 |
| `GET` | `/api/material-analysis/learnings` | 查询素材分析沉淀经验池，可按关键词、runId、decision、status 筛选 |
| `POST` | `/api/material-analysis/materials/:materialId/collect-knowledge` | 人工确认后将单素材沉淀到 `material-learnings.json`；负向素材会同步生成 Prompt Gate 避坑规则 |
| `POST` | `/api/material-analysis/directions/:directionKey/collect-knowledge` | 人工确认后将方向级表现沉淀到素材经验池；`directionKey` 需要 URL 编码 |
| `POST` | `/api/material-analysis/imports/:runId/collect-weekly-learnings` | 人工确认后批量沉淀本周经验，默认收录 3 条正向素材经验和 3 条负向避坑经验 |
| `POST` | `/api/material-analysis/learnings/:learningId/create-direction-draft` | 将一条素材经验转为本地成长方向草案，不直接进入正式方向库，参考图标记为待上传 |
| `POST` | `/api/material-analysis/materials/:materialId/create-direction-draft` | 将单素材方向转为本地成长方向草案，并自动补齐标签和画面核心描述 |
| `POST` | `/api/material-analysis/directions/:directionKey/create-direction-draft` | 将素材分析方向转为本地成长方向草案，并自动补齐方向库字段 |
| `GET` | `/api/material-analysis/creative-expansions/:expansionId` | 读取指定创意提示词池 |
| `POST` | `/api/material-analysis/creative-expansions/:expansionId/export-js` | 将提示词池导出为前端 JS 快照 |
| `POST` | `/api/material-analysis/materials/:materialId/vision/retry` | 重跑单素材视觉识别 |
| `GET` | `/api/material-analysis/imports/:runId/materials/:materialId` | 查看单素材详情 |
| `GET` | `/api/material-analysis/imports/:runId/materials/:materialId/image` | 代理读取单素材图片，供前端预览 |
