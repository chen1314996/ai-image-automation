## 2. `creative-table-parser.js`

### 目的

保留原有提示词查重逻辑，同时返回更完整的解析统计，方便前端日志解释“原始提示词数量”和“查重后提示词数量”的差异。

### 主要变更

- 新增 `extractCreativePromptResultFromRows(rows, sheetName)`。
- 保留 `extractCreativePromptsFromRows(rows, sheetName)` 兼容旧调用。
- 将 `seen` 从 `Set` 调整为 `Map`，记录第一次出现的行号、列号、方向和提示词标题。
- 发现重复时记录：
  - 当前重复行。
  - 首次出现行。
  - 当前提示词列。
  - 首次出现提示词列。
  - 当前方向。
  - 首次出现方向。
  - 当前提示词标题。
  - 首次出现提示词标题。
- 新增 `duplicateRowPairs`，按重复行对聚合重复提示词数量。
- `parseCreativePromptWorkbook()` 返回 `parseStats`。

### 新增统计结构

```js
parseStats: {
    totalPromptCount,
    dedupedPromptCount,
    duplicatePromptCount,
    duplicateRowPairs,
    duplicatePromptRows
}
```

## 5. `playwright-controller.js`

### 目的

解决量产页面无头模式启动完整工作流时弹出 `chrome-headless-shell.exe` 终端窗口的问题。

### 变更内容

无头模式下增加：

```js
if (useHeadless) {
    // Use full Chromium instead of chrome-headless-shell.exe so Windows does not show a shell window.
    contextOptions.channel = 'chromium';
}
```

### 原理

Playwright 默认行为：

```text
headless: true -> chromium-headless-shell
```

指定 `channel: 'chromium'` 后：

```text
headless: true + channel: chromium -> full Chromium / chrome.exe
```

### 验证结果

临时 Playwright 启动验证：

```text

executablePath: C:\Users\dd\AppData\Local\ms-playwright\chromium-1217\chrome-win64\chrome.exe
hasHeadlessShell: false
```
