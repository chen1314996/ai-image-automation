### 2. 创意拓展本地表格解析数量差异排查

**用户反馈**

创意拓展页面上传 `冰封末世创意方向拓展.xlsx` 后，页面只提示提取 1475 组提示词，但用户认为表格中应有 1925 组提示词。

**排查结论**

目标工作表为：

```text
新方向拓展表
```

表格结构为：

```text
385 个方向 x 每个方向 5 组提示词 = 1925 个提示词单元格
```

系统解析结果为：

```text
查重前：1925 组提示词
查重后：1475 组提示词
重复提示词单元格：450
重复行对：90
```

**关键判断**

系统原本对提示词正文做全表查重，同一段提示词文字只保留第一次出现。经用户确认，创意拓展页面确实需要查重，所以最终保留该逻辑。

### 5. 量产页面无头模式弹出终端窗口排查

**用户反馈**

量产页面启动完整工作流时，左侧会弹出一个黑色终端窗口，窗口标题为：

```text
C:\Users\dd\AppData\Local\ms-playwright\chromium_headless_shell-1217\chrome-headless-shell-win64\chrome-headless-shell.exe
```

**排查结论**

该窗口不是 Legil 页面，也不是业务弹窗，而是 Playwright 在 Windows 上默认启动的 `chrome-headless-shell.exe` 进程被 Windows Terminal 承载后显示出来。

Playwright 默认逻辑为：

```text
headless: true 且未指定 channel -> chromium-headless-shell
```

**修复方向**

无头模式下指定：

```js
channel: 'chromium'
```

这样 Playwright 会使用完整 Chromium：

```text
chromium-1217\chrome-win64\chrome.exe
```

而不是：

```text
chromium_headless_shell-1217\chrome-headless-shell.exe
```
