### 3. 建立 S8 素材分析经验沉淀能力

**完成内容**

- 新增 `src/services/material-analysis/knowledge-collector.js`。
- 支持单素材经验沉淀：
  - 写入 `material-learnings.json`。
  - 负向素材同步生成 `creative-memory.json` 中的 Prompt Gate 避坑规则。
  - 所有沉淀动作要求 `confirm=true`，避免误写入知识库。
- 支持方向级经验沉淀和本周经验批量沉淀。
- 支持将素材经验、单素材或方向聚合转为方向草稿：
  - 不直接写入正式方向库。
  - `referenceImageStatus` 标记为 `manual_pending`。
  - 保留标签、画面核心、风险说明和来源 run。
- `direction-selector` 可读取素材分析正向经验和避坑规则，影响自动选题排序。
- `Prompt Gate` 可读取素材分析生成的 memory rule，对风险 prompt 做解释性拒绝。
- 新增 `scripts/test-material-analysis-knowledge-collector.js` 和 `npm run test:s8-material-knowledge`。

**验证结果**

`npm run test:s8-material-knowledge` 通过，覆盖单素材正负向沉淀、周度经验沉淀、方向草稿生成、自动选题权重和 Prompt Gate 避坑规则。
