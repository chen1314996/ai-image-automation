## 2. Lumos Winky 统一入口

### `AGENTS.md`

- 新增 LLM Provider Rule。
- 要求所有新/改 LLM 功能使用 Lumos Winky。
- 规定 Winky 配置字段和 vision-capable LLM 的 `image_url` 格式。

### `doubao-automation.js`

- 将模块定位从“豆包大模型 API”改为历史 prompt-generation adapter。
- 保留旧方法名：
  - `uploadAndPrompt`
  - `fullAutomation`
  - `generatePromptsFromImage`
  - `callDoubaoVisionApi`
- 新增实际 Winky 调用：
  - `getStoredWinkyConfig()`
  - `callWinkyVisionApi()`
  - `validateConfigForRun()`
- 使用 `WINKY_API_KEY`、`WINKY_API_BASE_URL`、`WINKY_MODEL`、`WINKY_PROVIDER` 或本机 secrets。
- 对 Ark/Volcengine URL 做拦截。
- 响应中返回 `provider: lumos-winky` 和模型信息。

### `prompt-generation-service.js`

- 默认 provider 改为 `lumos`。
- 旧 provider 输入 `doubao`、`ark`、`volcengine` 归一为 Lumos。
- 对外 provider 列表只保留 `Lumos Winky`。
- 新增 Winky 模型列表读取、模型端点拼接、错误脱敏等逻辑。

### 路由和前端文案

- `src/routes/config.routes.js`：配置接口文案改为 Lumos Winky。
- `src/routes/doubao.routes.js`：历史路由说明改为兼容 wrapper。
- `src/routes/browser.routes.js`：打开网站时说明提示词模型无需网页。
- `feishu-control-service.js`：飞书状态卡片显示 Lumos Winky。
- `playwright-controller.js`：打开结果中不再显示豆包网页。
- `public/js/platform-config.js`：配置面板文案改为 Lumos Winky。
- `workflow-controller.js`：工作流日志显示 Lumos Winky 模型。
- `src/server/startup-banner.js`：启动 banner 精简并显示 Lumos Winky。
- `public/showcase.html`：展示页改为 Lumos Winky。
