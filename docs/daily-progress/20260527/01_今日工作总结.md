### 1. 统一提示词和视觉 LLM 到 Lumos Winky

**目标**

**完成内容**

- `prompt-generation-service.js` 将 `doubao`、`ark`、`volcengine` 等旧 provider 输入归一为 `lumos`，对外只展示 `Lumos Winky` provider。
- 更新配置接口、前端配置文案、浏览器打开提示、飞书状态文案、启动 banner、showcase 文案和工作流日志，不再把提示词阶段描述成需要打开豆包网页。

**完成内容**

- 前端新增 `public/js/creative-knowledge.js`，提供知识库页的方向树、资产列表、运行记录、反馈审核、方向收藏、方向草稿、记忆规则等交互。

### 3. 实现“运行一次自动创意”第一版闭环

**目标**

先做手动触发的一次性自动创意，不直接进入 24 小时循环。第一版重点是：能选方向、能拓展 prompt、能质检、能继续进 Legil、生图后能入库。

**完成内容**

- 新增 `src/services/creative-auto/`：
  - `direction-selector.js`：按方向状态、历史运行、TOP 素材洞察、优先级等选下一方向。
  - `prompt-gate.js`：对 Agent 输出 prompt 做质量检查、去重、数量限制和风险拦截。
  - `prompt-translator.js`：把 Agent prompt 转成更适合 Legil 的结构化文本。
  - `assets.js`：扫描输出目录，按照 run、prompt、文件名和保存记录写入资产索引。
  - `index.js`：串联 run-once 主流程、agentOnly、继续 Legil、运行记录和 scheduler state。
- 新增 `src/routes/creative-auto.routes.js`：
  - `/api/creative-auto/status`
  - `/api/creative-auto/suggestion`
  - `/api/creative-auto/run-once`
  - `/api/creative-auto/runs/:runId/start-legil`
  - `/api/creative-auto/runs/:runId`
- `creative-agent-service.js` 增加 `PROJECT_SETTINGS.md` 加载，默认加载新 skill `legil-run-once-prompt-contract`，并把 Agent 原始 Markdown 输出保存为 `rawText`、`rawTableMarkdown`，便于回溯和 Prompt Gate 使用。
- 前端 `public/js/creative-auto.js` 建立创意拓展页 S3 工作台：
  - 自动选题建议。
  - 手动选择方向或标签聚合。
  - agentOnly / smoke / full 模式。
  - Prompt Gate 结果面板。
  - 运行历史。
  - 从 Prompt Gate 继续启动 Legil。
- 默认参数与第一版 MVP 对齐：Nano Banana 2、1:1、2K、每条 prompt 4 张、headed、每日最多 1000 张、连续失败 5 次暂停。

**实际验证**

- `npm run test:creative-auto` 通过。
- `npm run test:s0-baseline` 通过，其中包含 agentOnly run-once 和小型 Legil stub 资产入库检查。

- 新增 `public/js/material-analysis.js` 和 `public/css/material-analysis.css`，建立素材分析前端页面：导入表格、查看 Top100、方向表现、视觉墙、报告、brief 和跳转创意拓展。
- `public/index.html`、`public/js/ui-core.js`、`public/css/app.css` 接入新的 `素材分析` 页面和样式。
