# 问题与解决方案 - 2026-06-05

## 问题 1：Legil prompt 规则散落，容易输出漂移

### 现象

Creative Agent、自动创意、表格 prompt 和 Legil 执行都需要相同的 prompt 质量要求，但规则分散在多个文件中。

### 原因

前期不同入口先独立跑通，prompt 约束逐步追加，缺少一个面向 Legil 生产的统一 skill。

### 解决方案

- 新增 `legil-creative-prompt-generator` skill。
- 将 prompt contract 和 quality gate 放入 references。
- 更新 agent README 和 agent.yaml。

### 结果

Legil prompt 生成有了更集中的规则入口，后续更容易让 Agent、表格入口和自动创意共用。

---

## 问题 2：表格 prompt 入口需要独立于自动创意

### 现象

人工策划表、飞书表和 prompt 表格可能并不走自动选题，也需要直接进入 Legil 批量生产。

### 原因

自动创意是系统自己选题和生成 prompt；表格 prompt 是人工或外部协作输入，二者来源不同。

### 解决方案

- 新增 `src/services/table-prompts/`。
- 新增 `src/routes/table-prompts.routes.js`。
- 新增 `public/js/table-prompt-batch.js` 和样式。
- Legil 路由适配表格 prompt 批量执行。

### 结果

表格 prompt 具备独立入口，后续可作为人工协作和批量生产的桥。

---

## 问题 3：视觉分类重命名有 weak/low 结果，需要复核

### 现象

991 个文件中，strong 653，weak 308，low 27。虽然 apply 了 988 个，但 weak/low 占比不低。

### 原因

视觉分类依赖方向库和图片识别；当画面同时具备多种元素，或者方向库粒度过细时，模型可能给出弱置信判断。

### 解决方案

- 保留 report.json/report.csv。
- 保留 undo-map.json。
- 后续抽检 weak/low 结果。
- 必要时调整 taxonomy、阈值和人工确认流程。

### 结果

本轮批量 apply 成功，但结果仍需要业务抽检，不能把 weak/low 当成完全无需复核。

## 问题 4：素材导入周次缺失

### 现象

5 月 TOP30 导入路径为 `未填写周次`。

### 原因

导入表或用户输入没有提供明确 weekId。

### 解决方案

- 当前先允许导入，保留 `未填写周次`。
- 后续在前端导入时要求填写周次或从文件名推断月份/周次。

### 结果

素材数据没有被阻断，但后续报告和趋势分析需要更稳定的时间维度。
