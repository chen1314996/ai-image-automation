## 1. 一句话定位

`素材分析` 页面用于把每周投放素材数据转化为可执行的创意判断：

```text
每周导入素材数据
  -> 自动识别 Top100 消耗素材
  -> 结合投放指标和 AI 视觉识别理解素材方向
  -> 判断素材健康度、方向生命力和项目阶段
  -> 输出周报、经验文档、迭代建议
  -> 联动创意拓展页和知识库页
  -> 让后续生图和选题持续进化
```

它不是一个单纯报表页，而是当前 AI 生图自动化平台里的“投放反馈大脑”。  
目标是让你每周都能快速回答：

1. 现在项目的素材状态健康吗？
2. 哪些方向在跑出，哪些方向正在疲劳？
3. 哪些图片值得拆解、复刻和继续拓展？
4. 哪些图片在烧钱、误导或需要停止复刻？
5. 下周应该生产什么方向、什么画面、什么变量？
6. 哪些经验应该沉淀到知识库，影响下一轮自动创意？

## 4. 页面用户价值

### 4.1 对每周复盘的价值

过去看表格时，需要人工从大量行里判断：

- 哪些素材花费最多；
- 哪些方向跑得好；
- 哪些素材只是点击高但转化差；
- 哪些画面值得继续生产；
- 哪些方向可能已经疲劳；
- 下周创意应该怎么安排。

`素材分析` 页面要把这些问题自动整理成：

```text
项目状态结论
方向排行榜
风险素材清单
优秀素材清单
画面内容洞察
下周创意计划
知识库沉淀建议
创意拓展输入建议
```

### 4.2 对项目生命判断的价值

系统要长期追踪项目是否处在以下阶段：

| 生命周期阶段 | 判断特征 |
| --- | --- |
| 冷启动验证期 | 素材量小，消耗分散，方向跑出不稳定 |
| 有效方向发现期 | 少数方向开始出现低 CPI、高 IPM 或正向 D0 ROI |
| 放量增长期 | Top 素材和 Top 方向能稳定贡献安装，D0 ROI 有支撑 |
| 稳定成熟期 | 多个方向可持续消耗，新素材仍能跑出 |
| 单点依赖期 | Top10 消耗占比过高，项目依赖少数爆款 |
| 素材疲劳期 | CTR 或 CVR 开始下降，老方向复刻效率变差 |
| 方向枯竭期 | 新方向跑出率下降，优秀素材主要来自旧方向 |
| 高风险消耗期 | 高消耗素材 D0 ROI、CPI、IPM 明显恶化 |

页面最终要让你一眼知道：

```text
当前不是只有“这周好不好”，而是“项目还在什么阶段，下一步该怎么救、怎么放、怎么拓”。
```

### 5.1 数据导入区

目标：每周快速导入投放数据。

- 输入项目名，默认可填 `无尽冬日`。
- 输入数据周期，例如 `2026-W21` 或 `2026-05-20 至 2026-05-26`。
- 自动识别字段。
- 自动跳过汇总行。
- 自动按花费取 Top100。
- 自动抽取图片 URL。
- 自动解析素材名称。
- 导入后写入 `data/material-analysis`。

字段识别规则：

| 标准字段 | 兼容别名 |
| --- | --- |
| `materialName` | 素材名称、素材名、name |
| `spend` | 花费、消耗、cost |
| `ctr` | CTR |
| `installs` | 安装、安装数 |
| `installShare` | 安装占比 |
| `cvr` | CVR |
| `cpi` | CPI |

### 5.2 项目总览区

目标：用少量指标说清楚当前项目健康情况。

核心指标卡：

| 指标 | 说明 |
| --- | --- |
| 总花费 | 当前周总消耗 |
| 总安装 | 当前周总安装 |
| 整体 CTR | 点击吸引力 |
| 整体 CVR | 点击到安装转化 |
| 整体 CPI | 获客成本 |
| 整体 IPM | 千次展示安装效率 |
| D0 ROI | 第一优先健康目标 |
| D0 ROI 覆盖率 | 有多少素材具备 D0 ROI 数据 |
| Top10 消耗占比 | 是否过度依赖少数素材 |
| Top100 消耗占比 | 头部素材集中度 |
| 有效方向数 | 达到健康规则的方向数量 |
| 风险方向数 | 高消耗低效或疲劳方向数量 |
| 新方向跑出数 | 新方向中表现达标的数量 |

项目健康结论示例：

```text
当前项目处于“单点放量 + 方向分化”状态。
Top100 素材贡献了主要消耗，说明头部素材决定项目走势。
D0 ROI 应作为第一观察指标，同时结合 CPI 和 IPM 判断早期素材是否值得继续放量。
本周建议优先拆解自然危机、探索发现中表现好的子方向，减少高消耗低 D0 ROI 的重复复刻。
```

### 5.3 健康度评分区

健康度不是单一数字，而是由 5 个维度组成。

| 维度 | 主要指标 | 权重建议 |
| --- | --- | --- |
| 回收健康 | D0 IAP ROI、D1/D7 ROI 辅助 | 35% |
| 获客效率 | CPI、IPM、CVR | 25% |
| 点击吸引 | CTR、CPM | 15% |
| 结构健康 | Top10/Top100 消耗集中度、方向分散度 | 15% |
| 新鲜度 | 新素材占比、新方向跑出率、重复方向占比 | 10% |

因为你确认优先看 D0 ROI，所以第一版排序和健康判断应以 `D0 IAP ROI` 为第一目标。

单素材健康标签：

| 标签 | 判断逻辑 |
| --- | --- |
| 高消耗高回收 | 花费高，D0 ROI 高于基准，CPI/IPM 不差 |
| 高消耗低回收 | 花费高，D0 ROI 低或为空，同时 CPI 高或 IPM 低 |
| 低消耗高潜力 | 花费不高，但 D0 ROI、CPI、IPM 表现好 |
| 点击强转化弱 | CTR 高，但 CVR 低或 CPI 高 |
| 转化强点击弱 | CTR 低，但 CVR、CPI 或 D0 ROI 好 |
| 回收观察中 | D0 ROI 缺失或样本不足 |
| 疑似疲劳 | 同方向多条素材消耗高但效率递减 |
| 可拆解复刻 | D0 ROI、CPI、IPM、安装量综合达标 |
| 暂停复刻 | 消耗足够但核心指标持续不达标 |

方向健康标签：

| 标签 | 含义 |
| --- | --- |
| 继续放量 | 已验证，值得继续扩展预算和素材 |
| 拆解复刻 | 表现好，但需要拆清楚有效变量 |
| 小预算验证 | 指标有潜力，但样本不足 |
| 控量观察 | 表现不稳定，避免直接大规模复刻 |
| 视觉换代 | 方向有效，但画面表达疑似疲劳 |
| 停止重复 | 多条素材已经证明当前表达无效 |
| 收录知识库 | 具备长期复用价值 |

### 5.6 AI 视觉识别区

第一版即接入 AI 视觉识别，默认针对 Top100 图片执行。

识别目标：

| 识别项 | 说明 |
| --- | --- |
| 主体 | 人物、动物、建筑、载具、物资、怪物等 |
| 场景 | 冰雪废墟、避难所、城市、室内、野外、道路等 |
| 事件 | 坠落、逃亡、发现、救援、攻击、迁徙、建造等 |
| 情绪 | 紧张、压迫、惊喜、绝望、希望、混乱等 |
| 构图 | 近景、远景、俯视、第一视角、中心构图、对角线等 |
| 色彩 | 冷蓝、暖光、强对比、低饱和、高饱和等 |
| 广告钩子 | 危机、稀缺资源、反差、选择、悬念、结果反馈等 |
| 可复用元素 | 值得保留的主体、镜头、情绪、道具 |
| 可替换元素 | 可迭代的场景、角色、冲突、道具 |
| 风险点 | 看不清、主体弱、信息过多、风格跑偏、文字风险等 |

视觉识别输出结构：

```json
{
  "materialId": "material_xxx",
  "visualDirection": "自然危机 / 坠落求生",
  "scene": "冰雪悬崖边缘，幸存者坠落或即将坠落",
  "mainSubject": "处于危险中的幸存者",
  "hook": "即时危机和救援悬念",
  "composition": "竖版纵深构图，危险点位于画面下方",
  "emotion": "紧张、惊险、求生",
  "retainElements": ["坠落危机", "人物求生动作", "冰雪环境"],
  "variationAxes": ["场景", "人物关系", "道具", "镜头角度", "结局反转"],
  "riskNotes": ["避免主体过小", "避免危险关系不清晰"]

```

识别执行策略：

- 默认只识别 Top100，避免成本失控。
- 每张图识别结果缓存到本地。
- 同一图片 URL 已识别过则复用缓存。
- 识别失败不阻塞整体导入，只标记为 `vision_failed`。
- 支持手动重跑单张或整批视觉识别。

`素材分析` 页面不直接替代创意拓展页，而是给创意拓展页提供更高质量的输入。

联动入口：

| 素材分析动作 | 创意拓展页接收内容 |
| --- | --- |
| 加入创意拓展 | 素材名称、图片 URL、指标表现、方向解析、AI 视觉识别结果 |
| 生成迭代方向 | 保留元素、替换变量、风险点、建议画面方向 |
| 生成下周计划 | 多个方向 brief，按优先级送入创意拓展 Agent |

传给创意拓展 Agent 的 brief 示例：

```text
请基于以下已验证素材进行方向迭代：

项目：无尽冬日
来源素材：题材 / 自然危机 / 妙思坠落危机
表现：花费高、安装多、D0 ROI 优先判断为正向，CPI 和 IPM 表现较好
AI 视觉识别：冰雪环境中的坠落危机，核心钩子是即时危险和救援悬念
必须保留：明确危机、人物求生动作、冰雪末世环境、强情绪反应
建议变化：场景、人物关系、道具、镜头角度、结局反转
避免：主体过小、危险关系不清、画面信息过杂

请输出 5 个新方向，每个方向给 5 条可用于 Legil 的高质量提示词。
```

## 10. 第一版验收标准

第一版完成时，应该满足：

1. 页面导航中出现 `素材分析`。
2. 可以导入当前样表。
3. 可以正确识别汇总行和明细行。
4. 可以按花费取 Top100。
5. 可以解析素材名称里的方向、创意点、尺寸。
6. 可以提取 `素材内容` 中的图片 URL。
7. 可以对 Top100 图片执行 AI 视觉识别并缓存。
8. 可以展示项目总览 KPI。
9. 可以展示方向表现地图。
10. 可以展示 Top100 素材墙。
11. 可以按 D0 ROI 优先输出健康判断。
12. 可以生成周报 Markdown。
13. 可以生成经验文档 Markdown。
14. 可以把导入数据写入 `data/material-analysis`。
15. 不影响现有页面和现有自动化流程。
