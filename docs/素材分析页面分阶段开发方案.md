# 素材分析页面分阶段开发方案

> 文档日期：2026-05-27  
> 页面名称：素材分析  
> 开发原则：新增能力，不破坏既有量产、改尺寸、创意拓展、知识库、重命名功能  
> 数据目录：`data/material-analysis`  
> 第一版核心口径：Top100 按 `花费` 排序，健康度优先看 `D0 IAP ROI`，第一版接入 AI 视觉识别

---

## 1. 开发总目标

把当前平台从“AI 生图自动化工具”升级为：

```text
投放数据分析
  + 素材画面理解
  + 方向健康判断
  + 创意迭代建议
  + 知识库经验沉淀
  + 创意拓展联动
```

第一阶段先做到每周导入表格后能分析 Top100 素材、识别图片内容、生成周报和经验文档。  
后续阶段再逐步做趋势、自动选题权重、创意拓展闭环、长期项目生命判断。

健康度规则优先级：

```text
1. D0 IAP ROI
2. 花费规模
3. CPI
4. IPM
5. CVR
6. CTR
7. D1-D7 ROI 辅助观察
8. 是否样本不足
```

素材标签规则：

| 标签 | 核心逻辑 |
| --- | --- |
| 高消耗高回收 | spend 高，D0 ROI 高于基准 |
| 高消耗低回收 | spend 高，D0 ROI 低或为空，同时 CPI/IPM 弱 |
| 低消耗高潜力 | spend 不高，但 D0 ROI、CPI、IPM 好 |
| 点击强转化弱 | CTR 高，CVR 或 CPI 弱 |
| 转化强点击弱 | CTR 低，但 CVR、CPI、D0 ROI 好 |
| 回收观察中 | D0 ROI 缺失或样本不足 |
| 疑似疲劳 | 同方向多素材效率递减 |
| 可拆解复刻 | 指标综合达标 |
| 暂停复刻 | 消耗足够但 D0 ROI/CPI/IPM 不达标 |

方向分析维度：

- 一级方向；
- 二级方向；
- 具体创意点；
- 尺寸；
- 渠道；
- Top100 占比；
- 消耗占比；
- 安装占比；
- D0 ROI 排名；
- CPI 排名；
- IPM 排名。

### 6.3 前端开发

新增 API：

| `/api/material-analysis/imports/:runId/vision/results` | GET | 获取识别结果 |
| `/api/material-analysis/materials/:materialId/vision/retry` | POST | 单素材重跑识别 |

```json
{
  "materialName": "...",

    "cpi": 4.7647,
    "ipm": 7.134,
    "ctr": 0.0428,
    "cvr": 0.1666
  },
  "parsedName": {
    "primary": "题材",
    "secondary": "自然危机",
    "idea": "妙思坠落危机"
  }

```

视觉识别输出：

```json
{
  "summary": "冰雪末世场景中的坠落危机画面",
  "mainSubject": "处于危险中的幸存者",
  "scene": "冰雪悬崖或废墟边缘",
  "event": "坠落、求生、救援",
  "emotion": "紧张、惊险、压迫",
  "composition": "竖版纵深构图",
  "color": "冷蓝环境光与局部暖光对比",
  "hook": "即时危机和救援悬念",
  "retainElements": ["坠落危机", "人物求生动作", "冰雪环境"],
  "variationAxes": ["场景", "人物关系", "道具", "镜头角度", "结局反转"],
  "riskNotes": ["主体不要过小", "危险关系必须一眼看清"],
  "suggestedDirection": "自然危机 / 坠落求生"
}
```

缓存目录：

```text
data/material-analysis/vision/cache/{imageHash}.json
```

执行策略：

- 默认只跑 Top100。
- 支持并发限制，例如每次 2-3 张。
- 失败重试 1-2 次。
- 失败后写入错误状态，不阻塞整批导入。
- 已识别过的 URL 直接复用缓存。
- 视觉识别过程通过 SSE 输出日志。

## 11. P7：跨周趋势判断

### 11.1 目标

当 `data/material-analysis` 积累多周后，系统能判断项目生命状态和方向趋势。

### 11.2 后端开发

新增文件：

```text
src/services/material-analysis/lifecycle-analyzer.js
```

新增 API：

| API | 方法 | 说明 |
| --- | --- | --- |
| `/api/material-analysis/trends/:projectName` | GET | 项目趋势 |
| `/api/material-analysis/trends/:projectName/directions` | GET | 方向趋势 |
| `/api/material-analysis/trends/:projectName/lifecycle` | GET | 项目生命周期判断 |

趋势指标：

- 总花费趋势；
- 安装趋势；
- D0 ROI 趋势；
- CPI 趋势；
- IPM 趋势；
- CTR 趋势；
- CVR 趋势；
- Top10 消耗占比趋势；
- Top100 消耗占比趋势；
- 有效方向数量趋势；
- 新方向跑出率；
- 老方向疲劳情况。

生命周期判断：

| 阶段 | 判断依据 |
| --- | --- |
| 冷启动验证期 | 有效数据少，方向跑出不稳定 |
| 有效方向发现期 | 少数方向开始出现正向 D0 ROI 和低 CPI |
| 放量增长期 | 多个方向稳定贡献消耗和安装 |
| 稳定成熟期 | 新旧方向都有稳定表现 |
| 单点依赖期 | Top10 消耗占比过高 |
| 素材疲劳期 | 旧方向 CTR/CVR/D0 ROI 连续下降 |
| 方向枯竭期 | 新方向跑出率持续下降 |
| 高风险消耗期 | 高消耗素材 D0 ROI 和 CPI 同时恶化 |

### 11.3 前端开发

新增模块：

- 趋势图；
- 方向趋势表；
- 项目生命周期卡；
- 连续周风险提醒；
- 方向成长/衰退榜。

### 11.4 验收标准

- 至少两周数据时能做环比。
- 多周数据时能显示趋势。
- 能输出生命周期判断。
- 能在周报中加入“相比上周变化”。

## 12. P8：自动进化闭环

### 12.1 目标

让素材分析结果影响下一轮自动创意，而不是只停留在报告里。

### 12.2 能力设计

自动创意选题时加入以下权重：

| 输入 | 对选题的影响 |
| --- | --- |
| 高 D0 ROI 方向 | 提高优先级 |
| 低 CPI 高 IPM 方向 | 提高测试优先级 |
| 高消耗低回收方向 | 降低或暂停 |
| 疑似疲劳方向 | 要求换画面机制，不允许简单复刻 |
| 正向视觉机制 | 注入创意拓展 prompt |
| 负向视觉机制 | 注入避坑规则 |
| 新方向跑出不足 | 提高探索型方向比例 |

### 12.3 自动生成下周任务

系统可输出：

```json
{
  "projectName": "无尽冬日",
  "weekId": "2026-W22",
  "creativeTasks": [
    {
      "priority": 1,
      "sourceDirection": "题材/自然危机/坠落危机",
      "taskType": "拆解复刻",
      "targetCount": 5,
      "reason": "D0 ROI 和 CPI 表现优先",
      "retainElements": ["即时危机", "人物求生动作"],
      "variationAxes": ["场景", "人物关系", "镜头"]
    }
  ]
}
```

### 12.4 验收标准

- 自动创意页能读取素材分析推荐。
- 知识库权重能受素材分析影响。
- 负样本规则能进入 Agent 上下文。
- 下周创意任务可以半自动生成。

## 14. 风险和注意事项

### 14.1 数据风险

| 风险 | 处理 |
| --- | --- |
| 字段名有变化 | 做字段别名识别和缺失提示 |
| ROI 数据为空 | 不直接判差，标记为回收观察中 |
| 样本太小 | 标记样本不足，不进入强判断 |
| 素材名称格式异常 | 保留原始名称，方向解析为空，允许人工补充 |
| 图片链接失效 | 标记图片不可用，视觉识别跳过 |

### 14.2 AI 视觉识别风险

| 风险 | 处理 |
| --- | --- |
| 成本过高 | 默认只识别 Top100，并缓存 |
| 识别失败 | 单张失败不阻塞批次 |
| 识别不准 | 保留人工修正入口 |
| 输出不结构化 | 强制 JSON schema 校验 |
| 图像下载慢 | 并发限制、超时、重试 |

### 14.3 产品风险

| 风险 | 处理 |
| --- | --- |
| 指标解释过度 | 报告区分“结论”和“推测” |
| 单指标误判 | D0 ROI 优先，但结合 CPI/IPM/CVR |
| 页面信息过载 | 默认展示摘要，详情折叠 |
| 影响旧流程 | 新增路由和页面，不修改旧接口行为 |

## 17. 第一版完成后的理想使用流程

```text
1. 每周拿到素材基础数据表
2. 打开平台 -> 素材分析
3. 输入项目名和周次

```

最终形成：

```text
数据看见问题
视觉识别解释问题
周报总结问题
创意拓展解决问题
知识库记住问题
下一轮自动创意少犯同样的问题
```
