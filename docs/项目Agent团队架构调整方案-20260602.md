# 项目 Agent 团队架构调整方案

> 日期：2026-06-02  
> 目标：在保留现有“参考图 -> 提示词 -> Legil”老流程的同时，把“素材分析 / 方向知识库 -> 创意 Agent -> Prompt Gate -> Legil -> 反馈学习”的新流程整理成统一前端、统一状态、统一执行队列的 Agent 团队架构。  
> 说明：参考 `C:\Users\dd\Downloads\agent-design.md` 的 Agent 分层思想，但不照搬 Lovart 项目结构。本项目中 Legil 与 Lovart 承担同类角色，都是生图执行平台。

## 1. 已确认方向

本方案基于以下已确认决策：

| 决策项 | 当前选择 |
| --- | --- |
| 主流程优先级 | 两条流程都保留，但前端和任务状态统一起来 |
| Agent 输出格式 | JSON 为主，前端再渲染成表格 |
| 默认自动化程度 | 默认全自动：Agent 生成后自动进入 Legil |
| 方向知识库主源 | `data/creative-knowledge/directions.json` 作为运行时主源，Excel / 飞书作为导入导出和协同源 |
| 反馈闭环粒度 | 图片 + prompt + 新方向是否值得入库 |
| 自动化任务表粒度 | 默认一行 = 一个任务方向，前端可按一级 / 二级 / 三级 / 子方向折叠聚合 |
| 任务表视觉整理 | 默认自动整理全部行，但支持暂停 / 继续 / 缓存，控制 Winky 调用消耗 |
| 任务表参考图用途 | 仅用于 AI 视觉整理、方向理解和前端预览，不默认作为 Legil 参考图上传 |
| 任务表默认模式 | 进入“创意拓展模式”，先由创意拓展 Agent 生成新方向 / prompt，再进入 Prompt Gate 和 Legil |
| 文档形态 | 新建完整“Agent 团队架构调整方案” |

## 2. 核心结论

当前项目不需要重做，而是需要把已有能力重新分层、命名、统一状态和统一数据契约。

推荐目标链路：

```text
方向知识库 / TOP 素材 / 自动化任务表 / 参考图 / 历史反馈
  -> 选题与预检 Agent
  -> 创意拓展 Agent
  -> 候选方向审核 Agent
  -> Legil Prompt 转译 Agent
  -> Prompt Gate Agent
  -> Legil 队列执行 Agent
  -> 资产登记 Agent
  -> 图片 / Prompt / 新方向反馈
  -> 反馈学习 Agent
  -> 知识库维护 Agent
  -> 下一轮自动创意
```

老流程继续保留：

```text
参考图文件夹
  -> Winky 视觉提示词 Agent
  -> Prompt Gate Agent
  -> Legil 队列执行 Agent
  -> 资产登记 Agent
  -> 反馈学习 Agent
```

两个流程共用：

- 统一任务状态中心
- 统一 Legil 队列
- 统一 Prompt Gate
- 统一资产登记
- 统一反馈学习
- 统一前端运行视图

这样可以避免老流程和新流程各跑各的，导致状态分散、图片归属分散、反馈无法复用。

新增“自动化任务表”入口后，推荐增加第三种输入形态：

```text
用户上传自动化任务表 xlsx
  -> 自动化任务表解析 Agent
  -> 提取每行方向、迭代描述、方向描述、嵌入参考图
  -> 一行生成一个 taskDirection，并按 一级/二级/三级/子方向 生成 groupKey
  -> 任务方向视觉整理 Agent
  -> 默认自动整理全部行，可暂停/继续/复用缓存
  -> 生成方向卡片、参考图摘要、创意核心、风险点、可拓展建议
  -> 前端按标签路径折叠聚合，用户自由勾选行级方向
  -> 创意拓展 Agent
  -> Prompt Gate
  -> Legil（不默认上传任务表参考图）
```

这个入口不是替代素材分析，也不是替代方向知识库，而是把人工策划表变成平台里的“可选择任务方向池”。

## 4. Agent 团队分层

参考文档中的分层可以迁移，但名称要贴合本项目。

| 层级 | Agent | 职责边界 |
| --- | --- | --- |
| 判断型 | 选题与预检 Agent、候选方向审核 Agent、Prompt Gate Agent、图像轻质检 Agent、任务方向预检 Agent | 不直接生图，不直接写知识库，负责风险、可执行性、去重和阻断 |
| 生成型 | Winky 视觉提示词 Agent、创意拓展 Agent、Legil Prompt 转译 Agent、灵感澄清 Agent、任务方向视觉整理 Agent | 负责生成结构化 JSON，不操作浏览器 |
| 执行型 | Legil 队列执行 Agent、资产登记 Agent、后处理交付 Agent | 操作浏览器、保存文件、登记结果，不评价创意好坏 |
| 学习型 | 反馈学习 Agent、知识库维护 Agent | 从反馈中沉淀规则和方向草案，但需确认后启用 |
| 对话型 | 项目运行助理 Agent、飞书运行助理 Agent | 解释状态、接受控制、生成建议，不默认改数据 |

### 5.3 自动化任务表解析 Agent

**建议新增。**

职责：

- 读取用户上传的自动化任务表 `.xlsx`。
- 识别工作表，例如 `自动化任务表`、`一二级标签定义`，当前默认忽略 `全量标签`。
- 解析每行方向字段：一级标签、二级标签、三级标签、子方向、迭代描述、方向描述。
- 提取嵌入在参考图列里的图片，并按行绑定。
- 将每一行转成平台内部的 `taskDirection`。
- 为每行生成 `groupKey`，供前端按一级 / 二级 / 三级 / 子方向折叠聚合展示。
- 标记任务表参考图用途：只参与视觉整理和预览，不作为 Legil 参考图上传。

从 `C:\Users\dd\Desktop\项目\sucai\无尽26-自动化任务表.xlsx` 观察到的表格结构：

| 工作表 | 作用 | 关键字段 / 内容 |
| --- | --- | --- |
| `自动化任务表` | 本次要跑的任务方向 | 108 行任务，列为一级标签、二级标签、三级标签、子方向、迭代描述、方向描述、参考图 |
| `全量标签` | 标签知识库和参考图 | 当前先忽略，不导入、不覆盖现有方向库；后续只作为导入预览来源 |
| `一二级标签定义` | 层级语义定义 | 一级标签概念解释、二级标签概念解释 |

图片结构：

- 工作簿内约 623 张媒体图。
- `自动化任务表` 有 198 个图片锚点，覆盖 108 行任务。
- `全量标签` 有 429 个图片锚点，覆盖 143 行标签。
- 这说明导入不能只读单元格文本，必须把 `自动化任务表` 的嵌入图按行导出并绑定到任务方向。
- 由于 `全量标签` 当前先忽略，默认不导出它的图片，也不生成 `tag-directions.json`。

已确认默认规则：

- 一行 = 一个任务方向，不把同标签路径的多行合并成同一个任务。
- 前端可以按一级 / 二级 / 三级 / 子方向聚合折叠，例如前 5 行同属 `题材/探索发现/发现物品/物品展示`，展示层可以折叠为一个分组。
- 默认自动对全部任务行做 AI 视觉整理，但任务可暂停 / 继续 / 缓存，避免 Winky 调用不可控。
- 任务方向视觉整理默认串行或低并发，推荐 1-2 个任务并行。
- 每行最多重试 3 次；失败后保留在“待重试 / 有风险”状态，不阻塞整表继续整理。
- 不做每日 Winky 调用上限，通过低并发、暂停 / 继续和缓存控制消耗。
- 任务表里的参考图不作为 Legil 参考图上传，只作为 AI 视觉理解和前端预览材料。
- 任务表方向不保存为正式方向，只保留在任务方向池或按需转为方向草案。
- 默认采用“创意拓展模式”：用户选择任务方向后，先进入创意拓展 Agent，再进入 Candidate Review、Prompt Gate 和 Legil。

### 5.4 任务方向视觉整理 Agent

**建议新增，复用素材分析的 AI 视觉识别体验。**

职责：

- 对自动化任务表中的每个任务方向进行行级整理。
- 像素材分析的 AI 视觉识别一样，读取参考图，输出视觉摘要、创意核心、保留元素、变化轴、风险点。
- 将一行表格变成前端可筛选的方向卡片。
- 默认自动整理全部行，并支持暂停 / 继续 / 跳过 / 重试 / 复用缓存。
- 默认串行或低并发运行，推荐 1-2 个任务并行，不设置每日 Winky 调用上限。
- 每行最多重试 3 次；失败后标记为“待重试 / 有风险”，继续整理后续任务行。
- 支持用户自由勾选多个方向进入创意拓展模式，再由 Prompt Gate 和 Legil 全自动生图。
- 使用参考图理解方向，但不把任务表参考图传给 Legil 作为生图参考图。

和素材分析 AI 视觉识别的区别：

| 对比项 | 素材分析 AI 视觉识别 | 任务方向视觉整理 Agent |
| --- | --- | --- |
| 输入 | TOP 素材表 / 素材图片链接 | 自动化任务表行 + 嵌入参考图 |
| 核心目的 | 从高表现素材中提炼经验 | 把人工策划方向整理成可执行任务池 |
| 输出对象 | 素材洞察 / brief | 任务方向卡片 / 可选拓展目标 |
| 是否依赖投放数据 | 是，包含 CTR、ROI 等 | 否，主要依赖标签、描述、参考图 |
| 后续流向 | 素材洞察 -> 自动选题 | 任务方向池 -> 用户勾选行级方向 -> 创意拓展模式 |

## 8. 全自动默认流程

用户确认默认全自动后，推荐行为如下：

```text
用户点击“运行一次自动创意”
  -> 选题与预检 Agent
  -> 创意拓展 Agent
  -> 候选方向审核 Agent
  -> Legil Prompt 转译 Agent
  -> Prompt Gate Agent
  -> 如果 acceptedPromptCount > 0，自动进入 Legil 队列
  -> Legil 生成并保存
  -> 资产登记
  -> 前端展示结果，等待反馈
```

默认阻断条件：

- Winky 配置不完整。
- Legil 正忙且不能排队。
- 输出目录不可写。
- `directions.json` 不存在或没有可运行方向。
- Candidate Review 全部 delete。
- Prompt Gate 接受 0 条 prompt。
- 连续失败超过阈值。

默认不阻断但记录 warning：

- 参考图不足。
- TOP 素材信号不足。
- 部分 prompt 被拒。
- 候选方向存在 revise 建议。
- 历史相似度中等。

- 多选方向。
- 单方向查看参考图和 AI 视觉整理。
- 暂停 / 继续任务方向视觉整理。
- 跳过单行或重试失败行。
- 发送选中方向到创意拓展模式。
- 选中方向经过创意拓展、Candidate Review、Prompt Gate 后全自动进入 Legil。
- 将某个任务方向保存为方向草案。

参考图策略：

- 任务表参考图用于 AI 视觉整理、方向理解和前端预览。
- 任务表参考图不默认作为 Legil 参考图上传。
- 如果未来需要“参考图锁定构图”的特殊模式，应作为高级开关单独启用，并在 run 里明确记录。

默认全自动链路：

```text
上传任务表
  -> 自动解析文本和嵌入图
  -> 默认自动对每行做视觉整理，可暂停/继续
  -> 前端按标签路径折叠展示，用户勾选行级任务方向
  -> 创意拓展 Agent
  -> Candidate Review
  -> Prompt Gate
  -> Legil（不默认上传任务表参考图）
```

### 9.5 方向知识库

展示：

- `directions.json` 方向树。
- 方向状态：seed / accepted / rejected / archived / disabled。
- 参考图覆盖。
- 方向草案。
- Excel 导入。
- 飞书同步。

### 9.6 创意拓展

展示：

- 同级样本。
- 八维覆盖缺口。
- Agent 输出候选方向。

- 如果来自任务表，展示源表行号、任务方向 ID、原始迭代描述和参考图。

### 9.8 Legil 队列与资产反馈

- 队列。

## 10. 方向知识库主源规则

运行时只认：

```text

```

Excel / 飞书定位：

| 来源 | 角色 |
| --- | --- |
| Excel `sucai/创意方向种子表.xlsx` | 初始导入、人工批量维护、备份 |
| 飞书方向表 | 团队协同、审核、外部编辑 |
| `directions.json` | 自动创意运行时主源 |

推荐同步规则：


## 13. 分阶段落地计划

### 阶段 1：统一状态和前端运行中心

目标：

- 两条主流程都能显示在同一个运行中心。
- 用户能看到当前 run、phase、Agent、Legil 队列状态。

要做：

- 定义统一 run schema。
- 给老 workflow 和 creative-auto 增加统一状态适配层。
- 前端新增“运行中心”视图。
- 飞书状态命令也读取统一状态。

验收：

```text
老流程和新流程任意一个启动后，前端都能看到统一 phase、进度、当前 Agent、是否可暂停/继续。
```

### 阶段 2：自动化任务表导入与任务方向池

目标：

- 用户上传类似 `无尽26-自动化任务表.xlsx` 的文件后，平台能读取每行方向和参考图。
- 默认一行生成一个任务方向，并可按一级 / 二级 / 三级 / 子方向折叠聚合展示。
- 每一行都能像素材分析视觉识别一样整理成方向卡片。
- 默认自动整理全部行，同时支持暂停 / 继续 / 缓存 / 重试。
- 默认串行或 1-2 个任务低并发整理；不设置每日 Winky 调用上限。
- 每行最多重试 3 次，失败后保留在“待重试 / 有风险”状态，不阻塞整表继续整理。
- 用户可以自由选择要进入创意拓展模式的方向。

要做：

- 新增任务表导入接口。
- 解析 `自动化任务表` 文本字段。
- 从 xlsx 中导出嵌入图片，并按行绑定。
- 当前默认忽略 `全量标签`，不导入、不覆盖正式方向库。
- 可选解析 `一二级标签定义` 作为展示解释或上下文补充。
- 新增任务方向视觉整理任务，复用 Lumos Winky 视觉识别能力。
- 视觉整理队列支持低并发、3 次重试、失败行可重试状态和缓存。
- 明确任务表参考图只用于 AI 视觉整理和预览，不默认上传给 Legil。
- 任务表方向不写入正式 `directions.json`，只保留在任务方向池；后续如需沉淀，走方向草案流程。
- 新增前端“自动化任务表 / 任务方向池”板块。

验收：


## 15. 仍需确认的问题

以下问题不影响当前架构方向，但会影响具体实现细节：

1. **全自动失败策略**  
   如果 Agent 生成方向后，候选方向审核只有 `revise` 没有 `keep`，是否允许自动继续进 Legil？  
   当前建议：允许低风险 `revise` 继续，但在 run 里打 warning。

2. **默认每轮规模**  
   当前代码默认常见配置是 1 个源方向、5 个新方向、每方向 5 条 prompt、每 prompt 4 张图。  
   是否继续作为全自动默认？  
   当前建议：继续保持，但支持单轮上限和队列上限；不设置每日 Winky 调用上限。

3. **老流程 Prompt Gate**  
   老流程的 Winky 参考图提示词是否也强制进入同一个 Prompt Gate？  
   当前建议：是。这样所有进入 Legil 的 prompt 都可追踪和去重。

4. **飞书写回节奏**  
   新方向入库后是否自动写回飞书，还是只生成写回预览？  
   当前建议：先生成写回预览，人工确认后写回。

5. **图片精选后是否自动加入参考图池**  
   当前建议：不自动。用户勾选“加入参考图”后再回流，避免污染参考图库。

6. **任务表方向入库策略**  
   已确认：任务表方向不保存为正式方向，不直接写入 `directions.json`。任务表行保留在 `task-directions.json` 对应的任务方向池中；如后续需要沉淀，只能走方向草案流程。

7. **任务方向视觉整理运行策略**  
   已确认：默认自动整理全部行；默认串行或低并发，推荐 1-2 个任务并行；每行最多重试 3 次；失败后保留在“待重试 / 有风险”状态，不阻塞整表继续整理；不做每日 Winky 调用上限。  
   实现建议：结果按 `taskDirectionId + referenceImageHash + descriptionHash` 缓存，避免重复消耗调用次数；暂停后从最近未完成或失败可重试行继续。

调整完成后，系统应当达到：

```text
老流程能继续稳定跑参考图批量生图；
自动化任务表能导入成行级、可折叠、可选择的任务方向池；
```

一句话目标：

```text
让项目从“能自动生图的工具”升级成“能持续学习、自动选题、自动拓展、自动投产、结果回流的创意生产 Agent 团队”。
```
