# S11 阶段 1：源比例识别和扫描复用记录

> 日期：2026-06-10  
> 对应方案：`docs/S11-源比例复用与逐张闭环三尺寸交付分阶段开发方案-20260610.md`  
> 阶段目标：扫描 OK 图时自动识别源图比例，并把匹配 target 初始化为 `source-reuse`，让匹配比例的 target 默认跳过 Legil。

---

## 1. 本阶段完成内容

### 1.1 store.js 扫描阶段读取源图尺寸

调整文件：

```text
src/services/delivery-postprocess/store.js
```

扫描 OK 图时现在会读取真实图片宽高，并写入 `sourceImage`：

```json
{
  "fileName": "ok_01_square.png",
  "width": 800,
  "height": 800,
  "dimensions": "800x800"
}
```

读取失败时不会让整个扫描崩掉，而是该图不进入源比例复用判断。

### 1.2 新增源比例匹配逻辑

新增判断逻辑：

```text
actualRatio = sourceWidth / sourceHeight
targetRatio = targetWidth / targetHeight

abs(actualRatio - targetRatio) / targetRatio <= 0.02
```

命中关系：

| 源图比例 | 复用 target |
| --- | --- |
| `1:1` | `800x800` |
| `16:9` | `1280x720` |
| `9:16` | `1080x1920` |
| 其它比例 | 不复用，三个尺寸保持 Legil |

如果意外命中多个目标比例，取误差最小的目标尺寸。

### 1.3 source-reuse target 初始化

命中源比例的 target 会被初始化为：

```json
{
  "size": "800x800",
  "aspectRatio": "1:1",
  "generationMode": "source-reuse",
  "reuseSource": true,
  "sourceRatioMatched": true,
  "sourceDimensions": "800x800",
  "status": "candidate_selected",
  "candidateCount": 1,
  "selectedCandidateId": "source_reuse_800x800",
  "candidates": [
    {
      "candidateId": "source_reuse_800x800",
      "source": "source-reuse",
      "selected": true
    }
  ]
}
```

未命中源比例的 target 保持 Legil 模式：

```json
{
  "generationMode": "legil",
  "reuseSource": false,
  "sourceRatioMatched": false,
  "status": "pending",
  "candidateCount": 4,
  "candidates": []
}
```

### 1.4 scan 汇总字段

`run.scan` 新增：

```json
{
  "targetCount": 12,
  "sourceReuseTargetCount": 3,
  "legilTargetCount": 9,
  "estimatedSavedTargetCount": 3
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `targetCount` | 本次扫描总 target 数，等于 OK 图数 x 目标尺寸数 |
| `sourceReuseTargetCount` | 源比例命中、跳过 Legil 的 target 数 |
| `legilTargetCount` | 仍需 Legil 生成的 target 数 |
| `estimatedSavedTargetCount` | 预计节省的 Legil target 数，当前等于 `sourceReuseTargetCount` |

### 1.5 任务收集层跳过 source-reuse

调整文件：

```text
src/routes/delivery.routes.js
```

`targetNeedsGeneration()` 现在会先判断：

```text
target.generationMode === "source-reuse" || target.reuseSource === true
```

命中时直接返回不需要生成，即使前端传入更高候选数，也不会把 source-reuse target 放进 Legil runnable tasks。
