# 当前项目设定：Legil 运行一次自动创意 MVP

最后同步日期：2026-06-02

## 当前业务目标

第一版只服务“运行一次自动创意”，不要直接做 24 小时循环。

默认闭环：

```text
创意知识库选题
  -> Agent 拓展候选新方向、八维标签和 prompt
  -> Prompt Gate 做格式校验、去重、风险过滤、数量截断
  -> Legil headed 模式串行生成图片
  -> 输出目录保存、资产索引和人工反馈
  -> Creative Memory 沉淀规则，下轮注入 Agent
```

Agent 是智能策划层，不是执行层。它不直接操作 Legil 浏览器，不直接改飞书或方向种子表，不直接评价图片好坏。

## Agent 默认产出规模

第一版默认处理 1 个原始方向。

每个原始方向默认生成：

```text
3 个新方向
每个新方向 4 条 prompt
合计 12 条 prompt
每条 prompt 由 Legil 生成 4 张图
理论单轮最多 48 张图
```

冒烟测试或不稳定阶段可以由调用层把 prompt 数截断到 2-5 条。

## 创意知识库输入

方向表字段：

```text
一级标签
二级标签
三级标签
细分标签
方向简述
参考图1
参考图2
参考图3
```

TOP 素材字段：

```text
素材名称
花费
CTR
CPI
D0 IAP ROI
D1 IAP ROI
D7 IAP ROI
素材内容
```

Agent 需要把 TOP 素材当作“选题和创意判断信号”，不要把它当成必须复刻的画面模板。

优先参考：

```text
CTR：点击吸引力
花费：投放验证强度
D7 IAP ROI：后端质量参考
CPI：成本风险参考
```

## Prompt 合约

每条 prompt 必须能直接给 Legil 生图。

每条 prompt 需要：

- 中文完整长提示词，不是关键词堆砌。
- 主题、画风、情绪氛围、画面内容、整体基调结构清楚。
- 一眼能看出主视觉、主体关系、场景机制、广告点击点。
- 默认适配 `1:1` 方图，构图中心稳定，缩略图可读。
- 默认适配 `Nano Banana 2 / 2K / 每 prompt 4 张`。
- 避免生成过度依赖细碎文字的小元素；如有画中文字，应短、醒目、可读。
- 不主动加入赛博、高科技 UI、悬浮设备、机甲、激光界面，除非源方向明确要求。
- 保持冰封末世、资源稀缺、现实废土、3D 卡通商业广告海报质感。

默认尾句：

```text
冰雪氛围，画面直观、主题明确，高质量3D卡通渲染，商业级游戏宣传海报风格，电影镜头感。
```

## Run-once 输出优先级

当输入里出现以下语义时，判定为后台自动创意任务：

```text
运行一次自动创意
run-once
creative-auto
Legil 自动生图
根据知识库自动拓展
```

这类任务优先输出 `新方向拓展表`，不要输出冗长策划文章。

表头必须稳定：

```text
参考方向
新方向名称
方向描述
来源于哪条详细迭代策略
提示词1
提示词2
提示词3
提示词4
提示词5
```

如果调用层明确要求完整分析，再输出四部分：

```text
参考图分析表
100组素材迭代策略总表
逐方向详细迭代策略表
新方向拓展表
```

同时输出 `candidateDirections` JSON 代码块，供程序解析和后续入库。表格与 JSON 必须表达同一批候选方向。

每个 JSON 候选方向至少包含：

```text
type
sourcePath
targetLevel
label
description
dimensions
duplicateRisk
reason
prompts
```

`dimensions` 必须覆盖 `mood / perspective / time / narrative / scale / material / subjectRelation / hook`。

## Prompt Gate 默认检查

Agent 输出后不会直接进入 Legil。Prompt Gate 默认检查：

- Markdown 表格或 JSON 是否可解析。
- 每行是否有方向名称、方向描述和 1-5 条 prompt。
- prompt 是否为中文完整长提示词，包含主题、画风、情绪氛围、画面内容、整体基调。
- 是否命中禁用元素：真实品牌、强赛博、高科技 UI、枪支、军事强相关物品、悬浮设备、机甲、激光界面、大面积英文、二次元赛璐璐。
- 是否过短、过抽象、关键词堆砌、与历史 prompt 高度相似。
- 单条 prompt 是否混写多个互斥画面方案。

## 后续同步规则

只要用户更新以下任一项，就必须同步更新本文件，并同步检查 `instructions.md`、`agent.yaml` 和相关 `skills/*/SKILL.md` 是否需要调整：

- Legil 模型、比例、分辨率、每 prompt 出图数量。
- 每日生成上限、单轮 prompt 数、失败暂停阈值。
- 输出目录、参考图目录、素材目录。
- 飞书通知策略。
- 世界观、美术风格、禁用元素、prompt 语言策略。
- 方向表或 TOP 素材表字段结构。

如果本文件和代码默认值冲突，以用户最新确认值为准，并优先修正代码默认值。
